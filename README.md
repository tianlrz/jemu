# Jemu · 简幕

一个以展示为中心、本地优先的轻量 HTML 展演工作间。当前预览版支持幻灯片与自由网页，包含轻编辑、版本历史，以及连接现有桌面 AI／CLI 的文件流程。

公开仓库：[tianlrz/jemu](https://github.com/tianlrz/jemu)。下载预览包见 [Releases](https://github.com/tianlrz/jemu/releases)。Windows 安装 Python 3.10+ 和 Edge 后，解压并双击 `Start.cmd`；也可用 `python server.py --desktop`。PPT 导出的可选组件见下方说明。工作库和账户设置只留在本机，发行包不含个人稿件、版本或凭据。

工作区与演讲者窗口不显示常驻产品 logo／名称，空间留给作品名称、内容与必要操作。产品名仍可用于系统窗口识别和导出文件。项目标识采用用户提供的 SVG，保存于 `assets/brand/`：`source.svg` 是原件，`logo-light.svg` 适合浅色背景，`logo-dark.svg` 适合深色背景，`logo.svg` 按 `prefers-color-scheme` 自动切换。这些是项目和外部识别用素材，客户端不加载；作品自己的校徽或其他内容标识不受影响。

## 产品核心：让 HTML 成为可演出的作品

Deck 是一种组织内容的方式。简幕希望承载的完整作品，可以从横屏讲解切换到竖向连续字幕，再通过点击某个元素放大进入视频播放，结束后回到原来的叙事位置。版式、比例、时间和交互应当服务于表达，不要求一份作品从头到尾都是同尺寸、逐页翻阅的幻灯片。

后续开发遵循以下方向：

- **作品自己决定表达。** 普通 HTML 可以保留滚动、响应式布局、动画、原生链接与视频；幻灯片、竖向字幕、连续叙事和局部放大可以共存于同一份作品。
- **播放与编辑分开。** 展示时点击由作品处理，可以进入细节或播放媒体；切到编辑时才接管选框、拖动和文字修改。避免用整页点击翻页覆盖作品已有交互。
- **简幕提供稳定的外壳。** 打开、开始／暂停、返回、复位、可选讲稿与计时、轻编辑、版本和存档由软件提供；作品无需重复生成整套控件。不适用的翻页或页码控件不强行显示。
- **AI 负责表达，文件保持开放。** AI 可以生成、诊断和修改 HTML/CSS/JavaScript；用户直接编辑产生的示例、意图与成稿可以交回 AI。无需先转换为专有格式或引入复杂的动画时间线编辑器。
- **只加载当前需要的内容。** 视频和较重的场景按需加载，离开时暂停并释放资源；不为预览、讲稿或缩略图反复复制整份作品。轻量化仍是功能取舍的约束。

**实现边界：**当前已提供「自动识别／自由网页／幻灯片」展示方式，播放时保留源 HTML 的布局、滚动、点击、键盘和媒体交互；编辑时才接管元素。作品自己实现的字幕、弹层视频和返回交互可直接运行。软件统一的混合场景控制协议、跨文件精确恢复动画／应用状态和媒体懒加载调度尚未完成，不能把后续方向当成全部已实现功能。

Windows 双击 **Start.cmd**。需要 Python 3.10+，优先使用这台电脑已有的运行环境；Edge 会打开独立应用窗口。也可以运行 `python server.py --desktop`。本版是本地服务加独立窗口，尚未打包成安装程序。

启动器为 `Start.cmd` 和可阅读的 `launch.pyw`，不使用 PowerShell 执行策略绕过、不下载远程代码，也不修改防护软件设置。`launch.pyw` 仅检查本机服务是否已启动，再打开本地窗口；日志在 `.runtime` 中。

默认载入复旦 12 页版式参考。选择「导入 HTML 稿件」可复制自己的 HTML 和素材文件夹；独立 HTML 也可直接导入。导入的是副本，原文件不变。稿件以普通文件保存在 `library/<稿件编号>/document/`，无需专有格式。仅导入你信任的 HTML；页面脚本会在本机浏览器中运行。

先点击「轻编辑」，再使用常见演示软件的操作：**单击选中，双击改字**。播放状态的点击留给源作品。对象周围显示方框和八个控制点，直接拖动边框移动，拖动控制点缩放；图片从角点缩放时保持比例，其他对象按住 Shift 拖动角点也可保持比例。选中对象后方向键移动 1 个稿件像素，Shift+方向键移动 10 个像素。「选上一级」用于选中完整卡片。文字仍可在右侧文字框修改。

选中对象后 Ctrl+C / Ctrl+V 复制粘贴，Ctrl+X 剪切，Ctrl+D 快速复制，Delete 删除；支持跨页粘贴并保留外观。粘贴对象会生成新的元素标识，复制的同源图片会尽可能内嵌到对象中，便于跨稿件使用。向画布粘贴普通文字会新建文本框，也可粘贴不超过 5 MB 的 PNG、JPEG、WebP 或 GIF 图片；对象剪贴板上限 8 MB。在文字输入模式和右侧输入框中，复制、粘贴及文字撤销仍使用浏览器原生操作。

右侧可更换字体、字号（pt）、加粗和斜体，字体也可手动填写；字体需要在本机可用，否则按浏览器规则回退。Ctrl+S 保存版本，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；保存后仍保留当前会话的撤销历史，重新打开或载入其他版本后则以该版本为新的起点。字体、移动、缩放、粘贴和删除都会进入编辑痕迹，随两种编辑物导出。含多个子元素的容器不能整块替换文字，以免损坏原布局。临时选框、控制点和输入属性不会写入成稿。当前支持整页图片式 PPTX 导出；自由绘图、艺术字和可编辑 PowerPoint 格式互操作留给后续版本。

每次保存、外部文件修改都会生成完整稿件快照。版本历史支持恢复，已保存的后续版本仍保留。外部 AI 与界面同时修改时，应用拒绝覆盖并提示你先下载草稿。草稿下载仅含 HTML；完整素材请使用「导出编辑物 → 完整编辑包」。历史文件和恢复前的文件保存在稿件目录中，当前版本不自动清理历史。

点击「导出编辑物」，填写想要的效果与后续检查范围，然后选择：

- **仅编辑痕迹**：下载 `jemu-edits.md`，包含页码、元素语义标识和定位、文字与位移的修改前后、元素位置、用户意图、版本记录以及相对首次导入原稿的最终文件差异。适合 AI 已有原稿的对话，直接上传这个 MD 即可。保存的详细操作跨会话留在磁盘，导出按下述预算提供近期记录并注明省略情况；版本恢复后，以最终差异为准，不应重复执行已撤销的操作。
- **完整编辑包**：下载 `jemu-full.zip`，包含当前 `document/` HTML 与全部素材、同一份 `edits.md`、结构化的 `changes.json` 和使用说明。解压后打开 `document/` 下的主 HTML 即可展示，也可整包交给 AI。当前成稿已应用编辑，AI 不应再次重复位移。

两种导出都会先保存尚未保存的界面编辑，并把最后一次导出副本保存在稿件目录的 `exports/` 中。仅编辑痕迹不携带完整图片与原稿；二进制或单个大于 2 MB 文件的内容差异会明确列为未包含，文字差异总量上限 8 MB。完整编辑包携带全部当前文件。本地完整版本快照不随这两种导出打包，备份历史请复制整个 `library`。

你可以把编辑物交给现有 AI 对话，或让可访问本机的 AI 直接修改 `document/`；文件更新后 Jemu 会重新载入并记录版本。相似页面的修复先要求 AI 给出范围和方案。此预览版不内置模型或终端。

通过 `Start.cmd` 或左下角「桌面窗口」打开后，点击「开始演示」，当前桌面窗口会移除标题栏和可调整边框，填满所在显示器（含任务栏区域），隐藏编辑界面。Esc 或「退出演示」恢复原窗口位置与大小，暂停计时并保留页码／内容。关闭服务前也会恢复仍在全屏的窗口。窗口控制只绑定本服务启动并验证过的 Jemu Edge 窗口，不接受任意窗口句柄或进程号。

幻灯片模式同时打开一个独立的**演讲者窗口**，显示本页讲稿、当前页／总页数、下一页标题和计时器；双屏时把主窗口放在投影屏、讲稿窗口放在自己的屏幕，再开始演示。讲稿窗口不复制整稿；翻页双向同步，关闭讲稿不退出观众画面。讲稿窗口也支持 Esc／「结束演示」恢复主窗口。自由网页默认不弹讲稿，可手动打开。

普通浏览器使用标准 Fullscreen API，并在保存前同步请求全屏。浏览器可能只允许一次点击中的全屏或弹窗，此时先单独打开演讲者窗口，再开始演示。内嵌浏览器若不支持系统全屏，会明确提示使用「桌面窗口」，不会把隐藏侧栏冒充全屏。无需关闭浏览器安全设置或安装 Electron。桌面无边框控制目前只支持 Windows。

常驻工具栏同时提供「撤销／重做」按钮（Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z）和「上一页／下一页」按钮（PageUp / PageDown；未选中对象时也可用方向键）。纯展示界面也有前后翻页、从头、讲稿和全屏按钮。Home / End 跳到首页／末页；文字输入与已选中对象的方向键保留编辑用途。

推荐让 AI 交付纯净内容 HTML：同级 `section.slide` 放在 `<main data-jemu-deck data-width="1920" data-height="1080">` 中，保留唯一页／元素标识和 `#speaker-notes` JSON 数组即可。Jemu 在内存中统一接管缩放、翻页、打印、讲稿与计时，不要求每份 HTML 自带工具条或运行时。页面直接位于 body 下的结构也可识别。保存与两种导出会剥离临时舞台、缩放和显示状态，继续保持源稿干净；旧版带 `deck-stage` 的稿件仍可使用。新工作间的复旦示例采用纯净内容版本。

演讲者窗口可以编辑、保存本页讲稿，并把修改写回 HTML 和版本历史。讲稿读取 `#speaker-notes` JSON 数组；无该数组时可读取页内 `data-notes` 或 `aside.notes`，保存时统一写入 JSON。计时支持暂停、继续、归零和计划时长提示（默认 8 分钟）；关闭演讲者窗口后仍可重新打开继续计时。「从头演示」或 R 回到第一页并重置计时；Esc 退出纯展示并暂停计时，不会重置编辑内容。纯展示窗口右上角移入鼠标后可退出、重新打开讲稿或全屏。编辑文字时方向键移动光标，不会误翻页。

明确的幻灯片走独立整稿 PDF／PPT 导出，完成后直接下载；自由网页使用原页面的系统打印。纯净稿的交互由 Jemu 提供，离开软件后可静态查看、打印；独立模式才自带翻页和讲稿窗口。

应用只监听 `127.0.0.1`，数据保存在本机，不需要登录。关闭窗口后服务仍可复用；左下角「退出服务」可停止服务。备份整个 `library` 目录即可带走稿件与历史。

复旦示例来自 [Fudan Slides](https://github.com/tianlrz/fudan-slides)。logo 权利属于其原权利人；模板中的紫色沿用用户设计，不代表官方标准色。

## 轻量化与内存预算

界面使用原生 HTML/CSS/JavaScript，服务只依赖 Python 标准库，不内置模型、终端、打包的 Chromium 或第三方前端框架。桌面窗口目前仍由已安装的 Edge 提供；预览版不是独立原生渲染器，浏览器内核、当前文档、字体及图片解码仍有基础开销，不能把服务内存等同于完整软件内存。

- 会话撤销最多保留最近 **100 步、估算 16 MiB**，大对象可能使可撤销步数更少。移动、缩放和字体修改只保留必要样式，不重复保存整块 HTML。达到预算会提示；当前内容和磁盘版本不会被删除，撤销到可保留的最早一步也不会误报已保存。
- 未保存的详细操作最多 **500 条、估算 2 MiB**，较早记录用明确的省略标记替代。文本示例最多 4,000 字，完整文字与素材仍在成稿中。保存后的记录独立放在 `versions/*.changes.json`；兼容旧版本内嵌记录。导出最多带最近 500 条、2 MiB 的详细记录，并注明未包含数量；磁盘上的旧记录继续保留，最终文件差异仍覆盖全稿。
- 同时只挂载当前稿件的一个预览。纯净稿隐藏的页不参与屏幕布局；不复制整稿到讲稿窗口。讲稿窗口关闭时不解析讲稿；打开时只在内容改变后同步正文，计时每秒发送小消息，关闭后释放引用。
- 外部修改检测每 **10 秒**只请求修订标识；隐藏窗口或演示时暂停检测，重新显示后立即检查。未变动文件通过大小及高精度修改时间复用哈希结果，仅缓存最多 8 个稿件的文件状态和修订标识，不缓存文件内容。没有选中对象时不运行选框跟踪计时器；离开页面释放定时器、观察器与缓存。
- 素材逐文件以二进制上传，避免整稿 Base64 转码。文件哈希、快照、恢复、HTTP 下载和完整 ZIP 导出采用 **64 KiB 分块处理**；ZIP 在磁盘生成，浏览器直接下载，不把整个包留在前端 Blob。导入总量上限 100 MiB，HTML 编辑上限 10 MiB，普通 JSON 请求上限 16 MiB。

2026-10-15 Windows 实测：含 48 MiB 素材的稿件完成流式导入、保存、连续 3 次完整导出及恢复，本地服务工作集从约 **26.3 MiB** 到采样峰值 **27.5 MiB**（增加约 1.2 MiB），导出文件哈希与恢复结果通过检查。此数字**不包含 Edge／Codex 浏览器进程**，也不代表所有源稿的固定上限。10,000 次编辑的缓存与撤销基线测试通过。

回归验证：`node tests/resources.test.cjs`；`python tests/memory_smoke.py`（Windows，使用临时库，不修改实际稿件）。后续功能继续遵守 [AGENTS.md](AGENTS.md) 中的资源约束。

## 云存档适配

左下角「设置」打开独立的 `/settings` 页面，集中管理存档位置、备份和恢复；编辑窗口保留原稿、草稿和撤销历史。用户界面不显示开发命令。

AI 通过 [MCP 接口](MCP.md)调用共用的设置、导入、文件、版本、导出、备份恢复和窗口编辑能力；入口为 `jemu_mcp.py`，提供 11 个结构化工具。MCP 按需运行，不使用 computer use，不新增网络监听端口。现有 [CLI](CLI.md)保留为 AI／开发兼容入口。MCP 配置已提供，具体客户端需要加载后才能使用，并未自动注册。

左下角「云存档」提供手动备份与恢复，支持**坚果云 WebDAV 直连**和**同步文件夹适配**。不新增云 SDK、后台同步进程或定时网络请求。

按作品规模选择位置：HTML 和少量 PNG 等图片推荐坚果云；视频、音频或附件较多时可选 Google Drive、OneDrive、夸克等云盘目录。界面按这两类展示选项，由用户决定，不自动切换服务或拆散作品。各方式仍备份完整作品和历史版本。

夸克选项使用**备份文件夹适配**：先在夸克客户端为本机某个文件夹开启备份，然后在简幕选择「夸克网盘 · 备份文件夹」并填入该路径。简幕只负责写入 ZIP 与索引，是否上传完成以夸克客户端为准，不包含夸克 API 登录或双向同步实现。换电脑恢复时，先通过夸克下载完整的 `Jemu Archives` 文件夹（包含 ZIP 和 JSON），关联它的上一级目录，再选择恢复。官方的文件夹备份说明见[安全备份](https://www.quark.cn/documents/help/safe-backup)。

坚果云直连（Windows）：

1. 在坚果云账户的安全设置中生成第三方应用密码，见[官方接入说明](https://help.jianguoyun.com/?p=2064)。这里使用账号邮箱和应用密码，不能填网页登录密码。
2. 在简幕选择「坚果云 · WebDAV 直连」，填入账号和应用密码，保存设置。服务器固定为官方 `https://dav.jianguoyun.com/dav/`，仅使用 HTTPS，不跟随重定向。保存本身不连接云端。
3. 点击「验证连接」检查目录读取权限，上传权限在实际备份时检查。点击「备份当前稿件」上传成稿、素材与全部版本；成功显示「云端服务器已接收」。上传后发布小索引，未完整发布的存档不会进入列表。
4. 点击「刷新」，按 UTC 存档月份查看列表，选择「恢复为新稿件」。另一台电脑重新配置自己的账号和应用密码，即可读取同一账号下的存档。

应用密码由 Windows DPAPI 加密保存在工作库 `.settings/webdav.secret`，绑定当前 Windows 用户；配置接口只返回是否已保存，密码不返回浏览器，也不进入作品导出或云端存档。不提供密码回显。断开关联清除本机密码与设置，保留云端已有文件。更换账号需重新填写应用密码；换机器也需重新配置。开发测试只用本机模拟 DAV 与虚构凭据，尚未经真实坚果云账号端到端验证。

每次备份都上传**包含完整历史的新包**，目前没有增量同步、自动合并或远端清理。适配器单包上限 450 MiB（低于官方 WebDAV 默认 500M 限制），原有导入稿件上限仍为 100 MiB。HTML、图片适合先用；大量视频和反复上传历史容易耗流量。官方免费版目前为每月上传 1 GB、下载 3 GB，详见[流量说明](https://help.jianguoyun.com/?p=3766)；请求频率和文件限制见接入说明。存档按 `Jemu Archives/YYYY-MM/DD/` 组织，每页最多读取 50 个小索引，内存索引缓存最多 100 条；目录响应达到服务器可能截断的上限时明确报错，不显示假装完整的列表。连接超时或限流后由用户手动重试。

同步文件夹方式：可选择 Google Drive、OneDrive、Dropbox 或其他云盘已经同步到本机的目录，保留其客户端负责登录和上传。选择品牌只用于区分位置，不代表简幕已经通过该厂商的 API 登录。Google Drive 的流式与镜像目录见[官方说明](https://support.google.com/drive/answer/13401938?hl=en)。

1. 在云盘客户端中配置一个能在本机访问的同步文件夹。
2. 在简幕「云存档」中填写该文件夹的完整路径，保存位置。
3. 点击「备份当前稿件」。简幕先保存界面编辑，再把成稿、素材、讲稿、全部历史版本和已保存详细操作写入该目录的 `Jemu Archives/`。
4. 在另一台电脑安装并登录相同云盘客户端，等待存档及索引同步完成，再在简幕中关联对应目录，选择「恢复为新稿件」。原稿和已有版本不被覆盖。

两种方式每次备份均生成唯一的 `.jemu.zip` 和小型 `.jemu.json` 索引。ZIP 内有 `document/`、`versions/`、`meta.json`、可选导出意图及包含逐文件 SHA-256 的 `manifest.json`。不备份登录状态、会话密钥、浏览器缓存、本机服务配置或冗余的导出 ZIP。取消关联保留所有已有存档。已同步到其他电脑后，再手动恢复；本版不合并多台电脑同时编辑同一文件的冲突。

备份在临时磁盘文件中流式生成，复制完成后才发布存档名称与索引；不新增后台轮询、同步进程或云 SDK。列表按每页 50 项只读小索引，避免为列文件名触发整份 ZIP 下载。恢复检查清单、路径和哈希后写入新稿件。单个存档的未压缩内容限 2 GiB、10,000 个文件；历史本身会占用云盘空间，本版不自动删除备份。

同步文件夹适配明确显示**「已写入同步目录」**，云端上传完成与否由云盘客户端报告。未配置实际目录时不会上传任何文件；测试使用独立的本地模拟目录，不包含实际 Google 账户的端到端验证。原生 Google Drive OAuth 和 Google Cloud Storage 存储桶尚未接入，后续可扩展存储适配器。Google Drive API 的独立接入需要 [OAuth 与相应权限](https://developers.google.com/workspace/drive/api/guides/about-sdk)。

存档与适配回归验证：`python tests/cloud_archives_test.py` 和 `python tests/webdav_test.py`；覆盖完整历史恢复、损坏检查、路径越界、重复存档、列表不读取 ZIP、本地 HTTP 接口上传／恢复、应用密码加密、限流和重定向不跟随。`memory_smoke.py` 同时覆盖 48 MiB 稿件的模拟云目录备份和恢复。

## HTML 兼容性

导入先复制稿件和素材到工作库，备份完整原稿。首次打开时自动生成并保存「Jemu 工作版本」；以后直接打开这份工作版本，不重复生成、不每次增加快照。旧项目在下次打开时完成同样的准备。准备、转换和排版期间只显示加载占位，完成后显示作品，避免先闪现原工具栏或未缩放页面。普通 HTML 也有一次工作版本快照，但保留原始字节、布局和交互。原稿和历次编辑都可在「版本」中找回。

明确的单页 React 幻灯片（`.deck-toolbar`、`.slide-canvas`，且提供“展开全部 N 页”入口）会在自动／幻灯片模式下准备全部页面，保存为固定尺寸、无原工具栏的完整静态 HTML 工作版本。已保存的渲染页中的文字、位移等修改会覆盖到对应页，避免被旧 React 初始化重置。普通 HTML、视频交互页和明确选择「自由网页」的作品继续按原方式运行。转换前的精确源稿已归档；要重新运行原始动态代码，可恢复原稿并选择「自由网页」。

此适配仅针对已识别的静态内容播放结构，不把任意按钮或网页导航猜成 deck 控件，不宣称可冻结任意 React 应用的内部交互状态。一次适配最多 200 页、源稿和展开后 HTML 各限 10 MiB；使用同一份预览 iframe，准备完成后释放原动态文档的运行环境。相对素材地址在预览中保留原基址，保存时去掉临时基址。若展开页数不符或超时，保留原网页并明确报错。

旧格式曾只把当前渲染页写入 HTML，因此首次适配时还会只读检查最近最多 8 个连续的“轻编辑保存”快照，恢复带编辑标识的其它页，并以每页最近一次快照为准。单页恢复上限 512 KiB、返回合计 4 MiB，逐份解压处理，不读取详细操作历史；遇到导入、外部重写或版本恢复边界即停止，不跨越边界复活已放弃的修改。这是有限的旧格式修复，并不保证恢复所有更早／超限快照。原快照不被修改，后续完整静态页组保存后不再需要此修复。

右上角在已识别的幻灯片中显示「保存整稿 PDF」和「保存 PPT」。屏幕仍只显示当前页；导出单独生成完整静态页组、复制素材到临时磁盘，再调用系统 Edge／Chromium 生成 PDF，不改动当前页或编辑状态。完成后直接下载文件。系统浏览器仅在导出时运行，完成或超时后释放；一时间只允许一项导出。PDF 在当前环境会验证实际页数与声明页数相同，避免单页误当整稿。普通自由网页仍使用原页面的浏览器打印功能。

PPT 为 `.pptx`：先生成 PDF，再将每页转为全幅 PNG 图片放入对应幻灯片，保持画面，不提供逐字编辑、原生图表、动画或视频。按页渲染并释放位图，默认图片长边 2560 像素；最多 200 页、每页 1200 万像素、素材与输出各 100 MiB。可选组件为 `pypdfium2` 和 Pillow，只在按需子进程使用；未安装时提示依赖，主服务保持标准库，不后台自动安装。当前 Codex 捆绑 Python 已有这两个组件；普通 Python 部署可按需安装 `python -m pip install pypdfium2 Pillow`。PDF 只要求系统浏览器，有 PDFium 时额外验证页数。

渲染任务返回稳定编号，可通过 CLI／MCP 查询和导出，不要求鼠标操作。最多保留四个任务摘要，派生文件有效期十分钟，后续请求触发清理；任务完成立即删除临时素材／浏览器配置。验证：`python tests/render_exports_test.py`（实际独立 PDF、逐页颜色、PPT 关系与图片数、并发限制、冲突、原稿不变）。系统打印参数参考 [Chromium Headless 文档](https://developer.chrome.com/docs/chromium/headless)，逐页渲染参考 [PDFium Python API](https://pypdfium2.readthedocs.io/en/stable/python_api.html)。

后续动态效果：先做可关闭的翻页转场、元素进入效果与减少动态效果偏好；播放使用动画，导出输出确定的静态画面。HTML 的原生交互继续保留。此部分尚未实现。

工作版本保存失败时会明确提示，源稿和已有备份仍保留；未保存的完整稿件可手动保存重试，PDF 和编辑物导出也会先尝试保存。写入仍检查基础版本，不能覆盖同时发生的外部编辑。AI／CLI 导入先归档原稿，不启动额外浏览器；动态作品在首次界面打开时完成转换。准备接口为 `POST /api/decks/{id}/prepare`（`baseRevision`、可选 `entry`、可选完整 `html`）；`jemuVersion` 元数据记录来源快照与工作版本。回归：`python tests/project_preparation_test.py`。

工具栏中的「展示方式」可在自动识别、自由网页、幻灯片之间切换，选择会随稿件保存。切换前会保存已做的编辑并重新载入页面。

| 内容形态 | 当前处理方式 |
| --- | --- |
| 普通网页、长页、竖向字幕、响应式布局 | 默认自由网页，原生滚动和交互，不强制 16:9，不伪造页码 |
| 单文件 HTML、相对路径 CSS／JS／ES 模块及素材文件夹 | 保留目录和路径，交由浏览器运行；需导入完整素材 |
| 源页面的按钮、链接、弹层、原生 SVG／Canvas／视频 | 展示状态保留原操作；按钮不被误识别为翻页或编辑 |
| `[data-jemu-deck]` 明确标记的平级页面 | 自动按模板画布适配，保留其宽高；支持横屏与竖屏 |
| 已验证的旧 `deck-stage` 模板 | 自动使用原运行时，简幕提供统一导航与讲稿 |
| 普通 `.slide`、嵌套幻灯片或未知框架 | 仅凭类名不接管；优先保留网页自己的运行时。手动选幻灯片时，只适配可识别的平级页面 |
| 多个本地 HTML 互相链接 | 保留导航，提供返回与回到入口；编辑保存到实际打开的子页面，不覆盖入口 |
| 中文 GBK 等旧编码 HTML | 浏览器依据 BOM／meta 识别，编辑保存时统一为 UTF-8 并更新声明；保留原 DOCTYPE／无 DOCTYPE 状态 |
| 视频／音频文件 | 支持单段 HTTP Range、HEAD 与正确的媒体 MIME，便于原生播放和定位 |

选择「自由网页」可以显式关闭模板接管；源文件也可使用 `<meta name="jemu:mode" content="native">` 或在 html 上标记 `data-jemu-mode="native"`。自由模式的方向键、字母键及剪贴板事件留给作品，进入编辑后才用于修改元素。幻灯片播放不再通过全局点击吞掉源作品的交互。切换稿件或重新载入时释放旧文档引用与会话撤销缓存；切换幻灯片会暂停离开的页面中的视频和音频。

兼容有边界：依赖服务端 API、运行中的构建工具、根绝对路径 `/assets/...` 或外部登录状态的项目，需要原来的服务环境或调整资源路径，本版不会自动启动其后台；跨域 iframe、Canvas／WebGL 内部对象和封闭 Shadow DOM 不支持逐对象编辑。动态框架中的 DOM 编辑保存的是当前 HTML 快照，不等于修改其组件源码；作品脚本重新渲染时可能覆盖该快照。媒体编码、自动播放和外部资源仍受浏览器及网络条件约束。复杂内容优先保证展示，无法直接编辑时保留原生运行，不强行转换。

「返回」可返回此前访问的网页地址，可能重新载入；原生弹层和场景内部的精确状态返回仍由作品自己的代码处理。PDF 分页遵循源 HTML 的打印样式，自由长页不会自动变成幻灯片。
